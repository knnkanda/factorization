# 因数分解ダンジョン

中学生向けの因数分解学習ゲームです。式を因数の形に戻しながら、展開して答えを確認できます。

## 学習ステージ

- 共通因数の森：共通因数を見つけてくくる
- 組み合わせ工場：積と和から二次式を因数分解する
- 平方の差の洞窟：`a² − b² = (a + b)(a − b)` を使う

最初の2ステージは2択、最後のステージは4択です。ヒントでは、共通因数や積・和の組み合わせを確認できます。間違えた場合は、選んだ因数を展開した結果も表示します。

## 起動方法

ビルドツールや外部ライブラリは使っていません。`dist/index.html` をブラウザで開くだけで動作します。

```text
dist/index.html
```
